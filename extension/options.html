Cómo avisar

Para mostrar avisos sobre las páginas, Chrome necesita permiso para todos los sitios. La extensión solo dibuja el aviso; no lee ni modifica el contenido de las páginas.

Los avisos críticos (atasco, tapa abierta, error, sin red) quedan en pantalla hasta que los cierres. En páginas internas de Chrome (pestaña nueva, chrome://, Web Store) no se puede dibujar el aviso flotante: ahí se usa la notificación de Windows.

Chrome tiene bloqueadas las notificaciones de Windows de esta extensión. Para reactivarlas, en chrome://extensions quita la extensión y vuelve a cargarla.
